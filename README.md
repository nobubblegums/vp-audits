# Vox Populi technical audits

Version-qualified technical references for coding agents and developers. Start with [AI knowledge](ai/README.md), or browse [mechanics](mechanics/) and [architecture](architecture/).

Read [source baselines and verification limits](ai/source-snapshots.md) before relying on a finding. Much of the recovered material concerns VP 5.2.6; selected unit-production contracts were revalidated against VP 5.4.8. A document’s scope and evidence labels determine which claims apply. These audits do not certify current VP behavior or the contents of a running game. Verify relevant claims against your task-selected source and configuration.

External recovered artifacts, source checkouts, DB snapshots and temporary test fixtures are not distributed. References to them identify historical evidence rather than files required to read this repository. Repository-local links connect the included supporting audits.

Local maintenance may retain an ignored original `ai/source-snapshots.local.md`; the public reference is `ai/source-snapshots.md`. No local policy or tooling is required to use these documents.
